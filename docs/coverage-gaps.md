# Coverage and operational gaps — October 20, 2026

The repository contains working bounded read-only probes and design artifacts. It does not contain a hosted tracker, database, recommendation model, inbox UI, email delivery integration or Google Calendar writer. All scheduled source flags remain disabled. URL counts and successful tests cannot establish campus-wide completeness.

## Remaining access and coverage gaps

- **Full HQ:** no authorized student session, member/group subscription or administrator event-only API secret. Use a supported user-provided subscription or an FSU-admin provisioned scoped feed with visibility and retention agreement. The verified public ICS route reduces the public gap but proves nothing about hidden/member events. Do not store an FSU password or guess an institutional key.
- **Social:** official authorized-account media probe is prepared but unrun without app/token/account/version. Meta documentation retrieval was partly rate-limited. Existing Apify dataset inspection is prepared but unrun without token/dataset; actor execution is absent. All arbitrary Stories, reshares, link stickers, expired media, consumer/private accounts, format completeness and latency remain unmeasured. A later seven-day 30–50-account pilot requires permission, current identity checks, a manual audit and a separate budget.
- **Private/member systems:** NoleNetwork, FS4U, Rec Connect registration and private GroupMe/Discord/Facebook announcements need their own allowed exports/submissions or approved bots. Public landing pages do not confer underlying access. Do not automate student accounts or install bots without organizer permission.
- **Manual/unsupported:** Yik Yak stays shared-lead/manual only, corroborated with an event source. No supported Facebook Groups collector exists in this project. Organizer submission/manual flyer forwarding is a future fallback, not a currently running channel.
- **Breadth:** most registry seeds remain untested. Small clubs, every college/department, engineering, GIS/geography, substantive library lectures, entrepreneurship, cultural agencies, Homecoming, Circus, sustainability, athletics and sports clubs need ongoing official-link discovery. Off-campus arts, venues, museums and outdoor/date opportunities are selected seeds, not live coverage. No roster or student profiles are collected.
- **Early actions:** observed event dates do not prove original announcement time. Ticket applications may open/close before event dates; watches must follow verified action evidence and cannot rely on stray date strings. No notification SLA, scarce-ticket warning or sellout prevention has been measured.
- **Understanding/review:** no extraction model, real-image OCR benchmark, deduplication implementation, recommendation ranking or authenticated inbox exists. Forty-four synthetic scenario descriptions plus one live reference specify expected behavior; they cannot establish field accuracy, image recall or recommendation quality.
- **Delivery/calendar:** no email delivered, inbound signature verified, OAuth connected, approval stored, outbox transaction run or calendar recovery executed. Save/alert/attendance approval/ticket-reminder approval remain separate contract requirements. No real calendar modifications occurred.
- **Operations/security:** hosting, authentication, migrations/RLS, private storage, signed uploads/webhooks, SSRF controls, backups/restore, durable health/cost ledgers and 14-day shadow operation remain implementation work. Offline guards in research scripts are not production security certification.

## Costs and risks

The core subscription subtotal can start at $35/month for Supabase Pro + Trigger Hobby, excluding hosting and all usage extras. The explicit paid scenario including Netlify Personal and assumed model work is $46.50/month before domain/tax/unmeasured overages. A constrained free-tier scenario is possible only under the modeled quotas/eligibility. None has been purchased.

The costed 39-account social pilot forecasts $41.15 incremental with a proposed, **unapproved** $45 cap. It assumes an existing paid/private storage allocation; modeled media exceeds Supabase Free storage. Account replacements, more memory, extra billing events, failed/empty checks, retries, video or different cadence can exceed it. `scripts/cost_model.py` reproduces assumptions; no forecast is an invoice or authorization. See [cost-model.md](cost-model.md).

Primary risks are inaccessible/unpublished sources, stale archives, source/vendor changes, silent empty results, incorrect date/action interpretation, repeated billing, private evidence leakage and duplicate/unapproved external actions. Mitigate through explicit source health, bounded audited windows, field evidence/conflict review, privacy/retention, caps, durable approval/outbox identity and human review. Every mitigation still needs implementation/evidence at its relevant stage.

Do not display a campus-wide coverage percentage. Report recall only for named accessible sources and manually audited time windows, with numerator, denominator, exclusions, misses and uncertainty. “Unknown,” “blocked,” “stale,” and “no eligible items observed in this validated window” are different states.

## Stage 1 implemented coverage

The central seven-day adapter and College of Music public preview now feed a real local SQL inbox: 293 central event IDs/332 occurrences plus ten Music cards. These are source-scoped records; cross-source matches remain separate until reviewed, so 303 records is not 303 audited unique campus opportunities. Public HQ snippets embedded in the central feed do not establish HQ member coverage. Withheld locations remain unknown, Music clock text has no verified timezone/end, and tickets/on-sale timing remain unverified.

The 59-route health catalog keeps all other routes disabled or explicitly unconfigured, stale, blocked or manual. Authenticated manual intake retains all supplied files and link/notes privately; no media extraction accuracy is claimed. The application has no mock event fallback. Hosted Auth/Storage/Trigger and safe retention cleanup remain unverified, so local live ingestion is not an operating production service. Later ranking, alerts, cross-source reconciliation and social breadth remain deferred.
